# Web3 from Zero

> A complete Web3 course for engineers who know how to code but have never touched crypto. Starts from "what is money" and ends with you reading smart contracts, running testnet transactions, and answering investor questions.

## Who this is for

You write code for a living — APIs, databases, maybe some ML — but you've never held a token, deployed a contract, or understood why any of this exists. This course will get you there in 16 chapters.

## How it works

| | |
|---|---|
| **16 chapters, in order** | Each builds on the one before. Budget 30–45 minutes per chapter |
| **🧒 Like you're 12** | The simple story, no jargon |

## The 60-Second Version

If you only have one minute:

1. A **blockchain** is a shared database that thousands of computers keep identical copies of, and nobody can secretly edit.
2. A **wallet** holds a **private key**. Whoever holds the key controls the money at that address.
3. A **smart contract** is a program that lives on the blockchain and runs exactly as written. Ours buy and sell fund claims.
4. **Gas** is the fee for running code on the chain. On **Arc** (Circle's chain) gas is paid in **USDC**.
5. A **stablecoin** is a token worth $1. **USDC** is Circle's, backed by cash and US Treasuries.
6. **RWA tokenization** turns real-world assets (bonds, funds) into tokens. It speeds up settlement but doesn't change a fund's rules.
7. **Earlyout** lets someone holding a tokenized fund that only pays out quarterly sell their pending redemption today, for USDC, at the fund's real NAV minus a spread that explains itself.
